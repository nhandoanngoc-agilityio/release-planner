# Intent home

One folder per feature kickoff: `intent/<YYYY-MM-DD>-<slug>/`. `/kickoff` creates it and `intent/CURRENT` points at the active one.

```text
intent/2026-10-28-<slug>/
  brief.md          the client's vague brief            (lead)
  intake.md         requirements, open questions, answers, BA decisions   (ba, lead)
  spec.md           the agreed contract                 (ba)
  tickets/T-NN-*.md one vertical slice each             (ba; qa and dev questions)
  test-matrix.md    test cases from the scenarios       (qa)
  state.md          stage, gate, dev rounds, log        (/kickoff)
  approvals/        gate-N.md, written only by the user's `approve gate N`
  scorecard.md      generated by scripts/score_kickoff.py
  client-truth.md   moved in from .kickoff-private/ at the reveal
  recall.md         hidden requirements vs tickets, at the reveal
```

A human makes every gate decision and every merge. Claude drafts, checks and flags.
